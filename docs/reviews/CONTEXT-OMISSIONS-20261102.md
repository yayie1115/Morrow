# 经用户批准的临时上下文排除 2026-11-02

## 范围

用户明确批准仅将本次故障中的三条助手技术自述临时排除出自动聊天上下文，保留网页原文、全部版本、用户消息、其他聊天和记忆。相关消息 ID 及实际排除配置只保存在服务器，不写入公开源码。

## 实现

get_history 在现有 settings 中读取 chat_context_omissions_v1，按会话选择正整数消息 ID；仅筛除对应助手行。用户消息即使误列入配置也不会被排除，其他会话不受影响。原始消息、版本、摘要和记忆不写入、不删除。移除该设置中的对应 ID 即可撤销。

这是用户批准的特定上下文恢复操作，不是对所有技术对话或符号进行自动删除；仍正常保留未被授权排除的引用。
