# Gemini 原生协议接入 2026-11-02

## 实现与上线

- 新增 gemini_native.py，原生 GenerateContent/SSE、x-goog-api-key 认证、JSON Schema 工具声明、图片内联、正文/思考摘要分流、原始用量保留与归一。
- 原生传输复用现有 Chat 工具权限、执行循环、持久化和行动回执；当前工具轮次保留上游原始 Parts 与 thoughtSignature，平行调用对应响应。历史无签名工具记录仅作为历史文字，不冒充可重放的签名调用。
- 原生四类主要 safetySettings 沿用既有 BLOCK_NONE 选择。使用原生参数路径发送，不再依赖 OpenAI 兼容层映射；不宣称取消平台限制或获得上游有效阈值回显。
- 提供方支持 Gemini 原生选项、原生模型列表读取。新增独立设置脚本，保留线上已拆分的主脚本及资源缓存。
- 每个模型增加可选 temperature、top_p，留空遵循模型默认；校验范围并保留 0。通过现有 models JSON 保存，无结构迁移。
- 同一提供方用作摘要时支持原生传输；截断、错误或不完整摘要不提交，不推进摘要边界。
- 经用户明确批准，现用 ofox 连接已切换为原生协议及对应地址；模型 ID、密钥、已有模型参数、人设、聊天和记忆未更改。

## 验证

- 编译及 JavaScript 语法检查通过。
- 全量离线回归 471 项：465 通过，6 跳过，0 失败。新增 10 项覆盖原生转换、工具签名/平行响应、真实共用循环、历史工具降级、终止/断线保护、思考与用量、摘要失败、采样参数透传。
- 独立合成数据库与无头浏览器真实 HTTP 检查通过：协议选择、温度零值展示、修改保存及重新读取。不是 iPhone Safari 用户验收。
- 使用配置好的 ofox 凭据进行了 3 次合成请求：2 次非流式工具调用/结果续轮及 1 次原生 SSE。均 HTTP 200，正常 STOP。SSE 真实返回可展示思考摘要和正文。
- 这 3 次合计输入 320 token、输出/思考 2059 token；未发送私人正文、未生成正式测试聊天。无大批量模型调用。不是缓存命中率测试。
- 部署时任务空闲；数据库一致性备份及独立副本恢复/完整性和表计数校验通过。精确源码基线校验、程序备份、平滑加载、上线后协议状态核对通过；HTTPS 和新设置资源 200。

## 限制与回退

- 本地/Git 与 VPS 有此前未同步的 harness 修改，本轮分别应用最小差异，不以本地旧 HTML 覆盖线上拆分脚本；提交不是线上全部源码的完整快照。
- 采样输入目前仅覆盖原生聊天，不擅自改变摘要模型温度、默认强度或现有 OpenAI/Anthropic 请求。
- 显式缓存、缓存保温、直接音频输入及图像生成未新增。当前语音识别转文字/图表路径不变。
- 超时、拦截、截断保留错误状态，不伪造回复或思考摘要；简单问题可能不返回思考摘要。
- 可先将连接恢复部署前协议和地址，再恢复旧程序。只恢复程序/连接配置，不使用旧数据库覆盖新消息。服务器私有备份与设置回退文件未提交。
- 下一步由用户刷新网页，在既有会话测试普通回复、思考摘要、记忆工具，并在设置展开模型检查温度/Top-P。实际缓存效果需后续真实用量观察。

## 当前运行状态补充

经用户明确要求，当前 ofox 提供方已恢复 OpenAI 兼容协议及原 API 地址。只改连接协议与地址，密钥、模型列表、采样配置、聊天、记忆及闹钟均未修改；不需要服务重启。

原因是原生适配把旧工具调用退化为助手普通文字，已观察到内部工具记录被复述。原生选项代码仍保留，但当前正式 ofox 连接不再使用它。本轮没有继续在线试修原生工具历史，也未将该问题标为已彻底修复。
